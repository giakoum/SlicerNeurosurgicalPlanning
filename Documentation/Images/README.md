# Documentation images

This directory holds public, de-identified screenshots of the NeurosurgicalPlanning extension.

Expected screenshots:

- `NeurosurgicalPlanning_3D.png`: multimodal 3D reconstruction, showing cortical surface, ventricular anatomy, skull context, and a tumor segmentation.
- `NeurosurgicalPlanning_Workflow.png`: the SurgicalPlanning `Final 3D Model` interface and its 3D output.

Only publish screenshots that have been reviewed for patient confidentiality, appropriate disclosure permissions, and potentially identifying embedded metadata. Do not commit patient imaging datasets, DICOM headers, or Slicer scene files containing patient data.

The example reconstruction is illustrative and does not establish clinical accuracy or validation of segmentation results.
